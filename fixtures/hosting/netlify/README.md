Recorded-shape Netlify API responses (field names from `netlify/open-api`'s swagger.yml; values invented, 2026-10) — used by `test/hosting.provider.netlify.test.ts` and kept as data stubs for local dev.
- `site.json` — `GET /api/v1/sites/{site_id}` (the probe). `deploys.production.json` — `GET /api/v1/sites/{site_id}/deploys?per_page=20&production=true`; `deploys.branch.json` — `…?per_page=20&branch=staging`. Between them every documented `state`, a `skipped: true` deploy and a CLI deploy with no commit.
- `user.json` — `GET /api/v1/user` (the token-only probe and the OAuth account label). `oauth-token.json` / `oauth-error.json` — `POST /oauth/token` answered 200 / 400. `error.401.json` / `error.404.json` — Netlify's `{ code, message }` error body.
- UNCONFIRMED against a live account: the deploy fields `committer`, `skipped` and `name` (outside the swagger's documented set or loosely typed there), the `error_message` Netlify writes for a canceled / ignored build ("Canceled build…"), the token response's `scope` / `created_at`, and the OAuth error body (an RFC 6749 shape is assumed).
