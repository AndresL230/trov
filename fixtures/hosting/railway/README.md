Railway public GraphQL API responses (`POST https://backboard.railway.com/graphql/v2`, `Authorization: Bearer <workspace or account token>`) in their recorded shape, for test/hosting.provider.railway.test.ts and as local design stubs (window: 2026-10-07 09:00–12:00 UTC; `ts` is unix seconds — 1791363600 is 09:00).

- `deployments.json` — `deployments(first: 20, input: { environmentId, serviceId }) { edges { node { id status createdAt statusUpdatedAt projectId url staticUrl meta } } }` (the schema's `Deployment`; railwayapp/cli `Deployments.graphql` asks the same list).
- `metrics-service.json` / `metrics-web.json` — `metrics(…, measurements: [CPU_USAGE, MEMORY_USAGE_GB] | [NETWORK_TX_GB], sampleRateSeconds: 3600) { measurement values { ts value } }` (the old usage poller's query). The `12:00` sample is the running hour and is dropped.
- `http-by-status.json` — `httpMetricsGroupedByStatus(…, stepSeconds: 3600) { statusCode samples { ts value } }`; `http-duration.json` — `httpDurationMetrics(…, stepSeconds: 3600) { samples { ts p50 p95 } }`. Both are in the public schema and are what railwayapp/cli runs for `railway metrics --http`, but docs.railway.com does not describe them.
- `probe-part.json` — `serviceInstance(environmentId, serviceId) { serviceName environmentId }` + `environment(id) { name projectId }` (the probe with a part); `workspace.json` — `workspace(workspaceId) { id name }` (the docs' workspace-token check); `projects.json` — `projects(first: 1)` (the probe with neither a part nor a workspace id).
- `graphql-error.json` — a refusal beside a 200 (how Railway reports one).
- UNCONFIRMED: the `meta` keys (`commitHash`, `branch`, `commitMessage`, `commitAuthor` — `meta` is an untyped JSON scalar); that `REMOVED` means "replaced by a newer deployment" (mapped `ready`); that `statusUpdatedAt` is when a deployment went live or failed; the dashboard deep link `railway.com/project/<p>/service/<s>?environmentId=<e>&id=<deployment>`; that an hourly `NETWORK_TX_GB` sample is the GB sent in that hour (binary GB); that an HTTP sample's `value` is the request count of its step, its `ts` the step's start, and p50 / p95 milliseconds; that a workspace token may run `projects(first: 1)` and the HTTP-metrics queries.
