Trov · Repo screen

A Repo screen for every repo setup

Twelve blocks and seven rules. Trov reads the facts it already has (apps, their kinds, which environments each targets) and the rules pick the Overview’s opener. The same data always draws the same screen. Every artboard below is drawn by that one engine from the scenario’s data.
