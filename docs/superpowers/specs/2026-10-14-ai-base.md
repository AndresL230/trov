## Handoff #10 (2026-10-15): verified before building

Checked live from `ai/screens` with the platform keys in `.dev.vars`:

- **Claude on the pinned SDK (0.133.0).** `messages.stream` with a tool and `cache_control` on the system block
  AND the tool definition: `claude-haiku-5-5`, `claude-sonnet-5-5` and `claude-opus-5-5` each streamed and stopped
  on `tool_use`; the first call wrote 2,117 cached tokens and the next read them. **Extended thinking with tool use
  and streaming works on `claude-opus-5-5`** with `thinking: {type: "adaptive"}` (`budget_tokens` is rejected on
  the 5.5 models), so Thinking stays on Opus. `client.messages.batches.list()` answered and `batches.create` exists:
  the Message Batches API is reachable.
- **Jev (TypeSafe, `POST https://api.typesafe.ai/v1/systemone`, model `jev-latest` → `jev-1.13.0`).** Three
  question types, several per request (one request may ask about one item several ways):
  - `noul` — `{type, instructions, criteria?: {true, false}}` → `{type: "noul", noul: 0..1}`.
  - `choice` — `{type, instructions, criteria: {<option>: description | null}}` (≤255 options) →
    `{type: "choice", choice, probabilities: {<option>: p}, confidence}` (probabilities sum to 1).
  - `score` — `{type, instructions, criteria: [level, …]}` (2–10 levels) →
    `{type: "score", score, legend: {"0": level, …}, probabilities: {"0": p, …}, confidence}`.
  - Body `{model, state, questions}`; answer `{model, answers: {<id>: …}, usage: {input_tokens, output_tokens}}`.
    Errors 400 / 401 / 413 / 415 / 422 / 429 / 529. One live call with all three types, 2026-10-15:
    `category` choice → `bug` 1.0; `severity` score → 1.29 (`Soon` 0.67); `urgent` noul → 0.85.
  - **So the pick-one kinds are ONE `choice` question**, not one yes/no per option.
- **The cron.** `CRON_SUBREQUEST_BUDGET` = 900 subrequests and `CRON_WALL_BUDGET_MS` = 8 min per invocation
  (`src/repo/dispatch.ts`). The AI pass runs only on ticks with no heavy job, after the health pings (2 per
  environment per org), at `AI_CALL_COST` 1 each: 12 calls a tick leaves the budget almost untouched for any
  plausible number of orgs. The pass harness in Phase B measures the real numbers.
- **Per-seat limits.** `LimitDef.per` is `"org" | "person"`; `PLANS` cannot say "per seat". Pro's `ai_chat` is
  computed as `cap × paid seats` (the `seats` override a paid org holds) at read time.
